# Разбор находок SAST (дефектная версия vulnerable/)

Инструменты: **Cppcheck 2.10**, **Flawfinder 2.0.20**, **Clang Static Analyzer 14**
(кроссплатформенная замена MSVC `/analyze`, см. `commands.md`).

Намеренные ошибки в коде: CWE-120 (`strcpy` в `char comment[64]`, строка 54) и
CWE-78 (`std::system` с именем файла без санитизации, строка 91).

## Пропущенные намеренные ошибки

- **Cppcheck** не сообщил ни о переполнении буфера (`strcpy` в `char[64]`), ни об
  инъекции команд через `std::system`. В версии 2.10 проверка `bufferAccessBufferOverwrite`
  не сработала на связке `std::string → strcpy(char[64])`, а `system()` сам по себе
  Cppcheck не помечает. Обе намеренные ошибки **пропущены** этим инструментом.
- **Clang Static Analyzer** не нашёл ничего (обе намеренные ошибки **пропущены**).
- **Flawfinder** нашёл обе намеренные ошибки (ID 1–3), плюс уровень риска самого буфера.

## Итог по дефектной версии

Уникальные подтверждённые проблемы безопасности: **2** (переполнение буфера,
инъекция команд). Нашёл обе — только Flawfinder. Ложные/несущественные срабатывания:
2 (Cppcheck style + шум конфигурации zlib).
