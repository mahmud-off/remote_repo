# Разбор находок SAST (уязвимая версия)

Исходные данные: `vulnerable/src/main.cpp` (96 строк). Две намеренные ошибки:

- **BUG-1** — строка 54: `strcpy(comment, first_line.c_str())` в фиксированный
  `char comment[64]` (строка 50) — CWE-120 / CWE-787;
- **BUG-2** — строка 84: `std::system(("type " + input_path).c_str())` без
  экранирования имени файла из argv — CWE-78.

## Пропущенные намеренные ошибки (по инструментам)

- **Cppcheck**: пропустил обе намеренные ошибки (BUG-1 и BUG-2). Его единственная
  находка по нашему коду — стилистическая (`constParameter`).
- **Clang Static Analyzer**: нашёл BUG-1 (strcpy); **не сообщил** об инъекции
  команд через `std::system` (BUG-2) — этот checker-пакет не помечает `system`
  как insecure API при динамической длине аргумента.
- **Flawfinder**: нашёл обе намеренные ошибки (BUG-1 — строки 50 и 54, BUG-2 —
  строка 84), но только по лексическим паттернам опасных функций, без анализа
  путей выполнения (потому и даёт «шум» уровня 2 на сам факт наличия массива).

## Итог по подтверждённым дефектам

Обе намеренные ошибки подтверждены минимум одним инструментом каждая и
дополнительно проверены вручную (чтение кода, тестовый запуск). Исправления
выполнены в `fixed/`, повторный анализ трёх инструментов подтвердил исчезновение
всех TP-находок (см. `reports/fixed/` и `reports/comparison.md`).
