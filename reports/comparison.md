# Сравнение трёх SAST-анализаторов

Инструменты (см. версии в `versions.txt`):
1. **Cppcheck 2.10** — универсальный статический анализатор;
2. **Flawfinder 2.0.20** — сканер типовых опасных вызовов C/C++;
3. **Clang Static Analyzer 14** — анализатор на основе абстрактного выполнения
   (кроссплатформенная замена MSVC `/analyze`, недоступного в среде генерации отчётов;
   команды для MSVC приведены в `commands.md`).

## До исправления (vulnerable/)

| Инструмент | Версия | Всего находок | Уникальные находки | Нашёл ошибку памяти (CWE-120) | Нашёл инъекцию команд (CWE-78) | Ложные/несущественные срабатывания | Пропущенные намеренные ошибки |
|------------|--------|----------------|-------------------|-------------------------------|--------------------------------|------------------------------------|-------------------------------|
| Cppcheck | 2.10 | 2 | 0 по безопасности | нет | нет | 2 (стиль `constParameter`, шум конфигурации zlib) | обе (CWE-120, CWE-78) |
| Flawfinder | 2.0.20 | 3 | 2 | да (`strcpy`, строка 54; буфер, строка 50) | да (`system`, строка 91) | 0 | нет |
| Clang Static Analyzer | 14.0.6 | 0 | 0 | нет | нет | 0 | обе (CWE-120, CWE-78) |

Выводы до исправления:
- Результаты инструментов **сильно различаются**: pattern-based Flawfinder нашёл обе
  закладку, тогда как Cppcheck (в данной конфигурации) и Clang SA — ничего по безопасности.
- Ни один инструмент не дал ложных «уязвимостей» уровня high; шум Cppcheck — стиль и сторонний код.
- Для надёжного покрытия нужно именно **три разных анализатора**, а не один.

## После исправления (fixed/)

| Инструмент | Подтверждённые проблемы остались | Остаточные находки | Комментарий |
|------------|----------------------------------|-------------------|-------------|
| Cppcheck 2.10 | нет | 1 стилистическая (`constParameter`) | Небезопасных вызовов больше нет |
| Flawfinder 2.0.20 | нет | 0 (Hits = 0) | `strcpy` и `system` удалены из кода |
| Clang Static Analyzer 14 | нет | 0 | Пустой вывод, exit=0 |

Также в fixed/ зависимость обновлена zlib 1.2.11 → 1.3.1, что устраняет
CVE-2018-25032 (проверено по NVD, см. `owasp-bdu.md`).

## Итоговое сравнение

- Уникальные подтверждённые уязвимости: 2 (обе нашли только Flawfinder).
- Вклад каждого инструмента: Flawfinder — обнаружение, Cppcheck/Clang SA — чистота
  повторного прогона после исправления (отсутствие прежних TP подтверждает корректность фикса).
- TP/FP-разбор по каждой находке: `findings.md`.
