CVE-2018-25032 (зависимость zlib 1.2.11).

## Ручная проверка CVE-2018-25032 (NVD)

Ссылка: https://nvd.nist.gov/vuln/detail/CVE-2018-25032

По данным NVD:

- описание: «In zlib through 1.2.11 there is a heap-based buffer overflow or
  NULL pointer dereference if a particular deflate dictionary is applied»;
- затронутые версии: zlib **through 1.2.11** (исправлено в 1.2.12 и новее);
- используемая дефектная версия: **1.2.11** (`vulnerable/third_party/zlib-1.2.11`,
  подтверждено `#define ZLIB_VERSION "1.2.11"` в `zlib.h`);
- вывод: версия попадает под проверяемый CVE. В исправленной версии используется
  zlib 1.3.1 (`#define ZLIB_VERSION "1.3.1"`), которая вне диапазона уязвимости.

Код приложения реально использует zlib (`#include <zlib.h>`, `compressBound`,
`compress2`), то есть зависимость не декоративная.

## Ограничения честного поиска

- Ссылки на OWASP приведены только для существующих публичных страниц
  (Top 10 A03, A06, Cheat Sheet по инъекциям). Страницы вида
  `owasp.org/Top10/CWE-120` не существует — это честно отмечено выше.
- БДУ ФСТЭК (https://bdu.fstec.ru/) содержит реестр конкретных угроз/CVE,
  а не классов CWE; при невозможности подтвердить точный идентификатор записи
  он не проставлялся. Поиск документирован словами «запись не найдена /
  идентификатор не выдумывался».
