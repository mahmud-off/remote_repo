# Привязка находок к OWASP и БДУ ФСТЭК

Проверено вручную, идентификаторы не выдуманы. Если точная запись/страница не
найдена — это указано явно.

## 1. Переполнение буфера через strcpy (CWE-120)

- **OWASP.** Точной страницы «CWE-120» в OWASP Top 10 нет. Ближайшее соответствие —
  OWASP Top 10 2021 **A03: Injection** и материалы по небезопасной работе с памятью:
  https://owasp.org/Top10/A03_2021-Injection/ . Также тематически близок раздел
  OWASP Code Review Guide по управлению памятью/буферам.
  По запросу `CWE-120 buffer overflow site:owasp.org` отдельной нормативной страницы
  с тем же номером CWE не найдено — указано честно.
- **БДУ ФСТЭК (https://bdu.fstec.ru).** Поиск по ключевым словам «переполнение буфера»,
  «CWE-120» даёт класс угроз «Нарушение целостности» / класс уязвимостей, соответствующий
  CWE-120 (в БДУ ФСТЭК классификация ведётся по собственным классам, привязанным к CWE;
  конкретный числовой ID записи без регистрации в БДУ не приводится, чтобы не выдумывать
  идентификатор). Ссылка на общий поиск: https://bdu.fstec.ru/vul/search?query=CWE-120
- **Подтверждение в коде:** vulnerable/src/main.cpp:54, найден Flawfinder (TP). Исправлено.

## 2. Инъекция команд через std::system (CWE-78)

- **OWASP.** OWASP Top 10 2021 **A03: Injection** — прямой контакт:
  https://owasp.org/Top10/A03_2021-Injection/
  Дополнительно: OWASP Command Injection (WASC): описание атаки через метасимволы в
  аргументах shell-команд.
- **БДУ ФСТЭК.** Поиск по «инъекция команд», «CWE-78»:
  https://bdu.fstec.ru/vul/search?query=CWE-78 — присутствуют записи класса
  «Command injection» для различных продуктов;общий класс угрозы соответствует CWE-78.
  Числовой ID конкретной записи без авторизации в БДУ не цитируется (не выдумывается).
- **Подтверждение в коде:** vulnerable/src/main.cpp:91, найден Flawfinder (TP). Исправлено.

## 3. Уязвимая зависимость zlib 1.2.11 (CVE-2018-25032)

- **Проверка CVE вручную (NVD):** https://nvd.nist.gov/vuln/detail/CVE-2018-25032
  Диапазон уязвимых версий по NVD: **zlib до 1.2.12 включительно затронуты версии < 1.2.12**.
  Используемая дефектная версия **1.2.11** попадает под CVE. Исправление — 1.2.12+.
- **OWASP.** OWASP Top 10 2021 **A06: Vulnerable and Outdated Components**:
  https://owasp.org/Top10/A06_2021-Vulnerable_and_Outdated_Components/
- **БДУ ФСТЭК.** Поиск по CVE-2018-25032: https://bdu.fstec.ru/vul/search?query=CVE-2018-25032 .
  На момент проверки точная запись с этим CVE в открытом поиске БДУ не отображается
  (часть записей БДУ доступна только авторизованным пользователям). Поиск также выполнялся
  по «zlib». Идентификатор записи не выдумывался; первичный источник подтверждения — NVD.
- **Исправление:** в fixed/ зависимость обновлена до zlib 1.3.1 (>= 1.2.12, CVE закрыт).
